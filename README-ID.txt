OFERO CHARGER OFFLINE - ANDROID PROJECT

Isi:
- Kalkulator offline single dan paralel 2 baterai
- Preset 48V 59Ah, 48V 24Ah, 60V 24Ah, 72V 30Ah, 72V 55Ah
- Li-ion umum: 48V 13S (54,6V penuh), 60V 16S (67,2V penuh), 72V 20S (84,0V penuh)
- Arus charger, SOC awal/target, tarif PLN, efisiensi, estimasi waktu/energi/biaya
- Semua aset lokal; tidak memerlukan permission INTERNET

CARA MEMBUAT APK:
1. Ekstrak ZIP.
2. Buka folder OferoChargerOffline melalui Android Studio.
3. Tunggu Gradle Sync.
4. Pilih Build > Build Bundle(s) / APK(s) > Build APK(s).
5. APK debug akan ada di app/build/outputs/apk/debug/app-debug.apk

Catatan:
Project ini adalah source Android Studio, bukan APK yang sudah dikompilasi.
Perkiraan waktu memakai tambahan 15% untuk fase taper/balancing; bukan pengganti spesifikasi charger/BMS.
